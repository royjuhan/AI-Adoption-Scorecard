# 수용 기준: signoff-final 3단계 기준 구간 고르기(흔들린 기록)

## 기준 숫자

- 정확도 95% 이상(기준 자료와 허용 오차 안에서 일치한 항목 / 기준 항목).
- 누락률 2% 이하.
- 시간 조건은 보지 않는다(`time_must_drop: false`). 건당 시간은 잰다.
- 지금 검증: 정확도 80.0%, 누락률 5.0%, 판정 `hold`.

## 테스트 시나리오

- `samples/output.csv`를 기준 자료로 두고, 같은 열을 내는 결과를 `scorecard check`로 대조한다. 정확도 100.0%, 누락률 0.0%여야 한다.
- 키 `record_id` 행 하나를 빼면 누락 1건으로 센다.
- `range_start`: 허용 오차 경계의 값은 일치, 넘으면 불일치로 센다.
- `range_end`: 허용 오차 경계의 값은 일치, 넘으면 불일치로 센다.
- `range_avg`: 허용 오차 경계의 값은 일치, 넘으면 불일치로 센다.
- 규칙에 맞지 않는 건은 결과에 넣지 않고 사람 검토 목록으로 보낸다.
- 같은 입력을 두 번 돌리면 같은 바이트가 나온다.
- 네트워크를 끊고 돌려도 같은 결과가 나온다.
