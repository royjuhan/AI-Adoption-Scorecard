# 리드 세션 시작 메시지

docs/README-instructions.md를 읽어. 너는 이 저장소 AI-Adoption-Scorecard의 리드 세션이다.

- 14절 순서대로 시작한다. 사람 승인이 필요한 지점(스펙 승인, PR 머지, 게이트)에서는 반드시 멈추고 나에게 묻는다.
- 작업 카드는 동시에 2개까지만 연다.
- 한 단계가 끝날 때마다 무엇을 만들었는지 세 줄로 보고한다.
- 이미 된 것: git init, 첫 커밋(지시문, .gitignore), 브랜치 main, repo-local user.name/email. remote origin은 https://github.com/royjuhan/AI-Adoption-Scorecard.git 으로 이미 설정됨. 아직 안 된 것: push. 시작하자마자 `git push -u origin main`을 먼저 한다.
