# new-case (골격)

사용자 입구는 /scorecard

1. `cases/<name>/` 폴더를 만든다. `cases/`는 커밋하지 않는다.
2. `case.yaml` 골격을 만든다. 스키마는 docs/spec/case-schema.md.
3. 사용자 서술을 `intake.md`에 그대로 저장한다.
4. `reference/`, `candidate/` 폴더를 만든다.
5. 익명화 체크리스트: 품번·이름·이메일·경로가 없는가. (미정: 세부 항목)
