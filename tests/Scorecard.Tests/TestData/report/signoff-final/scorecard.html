담당자 확인
  • 3단계 예외 건 담당자 검토: 규칙으로 판단이 안 되는 예외 건은 담당자가 검토한다.
    엔진 문장판단 기준을 일부만 글로 쓸 수 있으므로(partial) 예외 건은 사람이 검토한다.
  • 6단계 담당자 확인: 이 단계 결과를 다음으로 넘기기 전에 담당자가 확인한다.
    엔진 문장틀리면 외부에 영향이 있으므로(external) 이 단계 뒤에 사람 게이트를 둔다.
  • 7단계 담당자 서명: 담당자가 최종 확인·서명한다.
    엔진 문장사람이 최종 확인·서명하는 단계이므로(yes) 사람이 하는 것으로 분류.
남는 위험
  • 6단계 결과 해석 문장 쓰기: AI 초안이 틀릴 수 있다. 자동 승인하지 않고 담당자가 확인해 잡는다.
  • 검증 판정이 보류다. 정확도 80.0%가 문턱 95%에 못 미치므로 보류.

업무 요약과 입력 기록

입력 원문 보기
매주 기록 파일이 20개쯤 들어온다. 파일을 열어 필요 없는 줄을 지우고 정리한다. 파일마다 값이 안정된 기준 구간을 하나 고른다. 구간의 시작과 끝을 적고, 그 구간의 평균값을 낸다. 정리, 안정된 기록의 구간 고르기, 값 계산, 보고서 채우기는 지금 직접 만든 매크로가 한다. 쓰는 프로그램에는 이 기능이 없다. 20개 중 6개쯤은 기록이 흔들린다. 이런 파일은 사람이 직접 구간을 고른다. 그중 절반쯤은 어디를 골라야 할지 애매하다. 보고서에는 결과가 무슨 뜻인지 해석 문장을 쓴다. 해석하는 기준은 글로 정리되어 있지 않다. 보고서는 밖으로 나가므로 틀리면 곤란하다. 마지막에 담당자가 보고서를 확인하고 서명해서 제출한다. 서명은 사람이 책임진다. 같은 기록 파일을 AI에게 주고 구간과 평균값을 받아 본 결과가 있다. 사람이 고른 값과 맞는지 비교하고 싶다.
단계 흐름
  1. 기록 파일 열기·정리 규칙 자동화 검토
  2. 기준 구간 고르기(안정 기록) 규칙 자동화 검토
  3. 기준 구간 고르기(흔들린 기록) 규칙 자동화 검토
  4. 구간 값 계산·옮기기 규칙 자동화 검토
  5. 보고서 양식 채우기 규칙 자동화 검토
  6. 결과 해석 문장 쓰기 AI 초안 + 담당자 확인
  7. 최종 확인·서명·제출 담당자 직접 처리
