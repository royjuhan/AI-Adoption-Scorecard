# 수용 기준: mixed-exceptions 1단계 메일 접수 기록

## 기준 숫자

- 정확도 95% 이상(기준 자료와 허용 오차 안에서 일치한 항목 / 기준 항목).
- 누락률 2% 이하.
- 처리+검토 시간이 적용 전보다 줄어야 한다.
- 지금 검증: 미검증. 검증 자료(case.yaml inputs)가 없어 미검증.

## 테스트 시나리오

- 출력 열이 정해지면 그 열로 기준 자료를 만들고 `scorecard check`로 대조한다.
- 같은 입력을 두 번 돌리면 같은 바이트가 나온다.
- 네트워크를 끊고 돌려도 같은 결과가 나온다.
